# Artificial Intelligence Labs

Лабораторные работы по машинному обучению.

## Содержание

- Lab 1: KNN
- Lab 2: Логистическая и линейная регрессия
- Lab 3: Решающее дерево
- Lab 4: Случайный лес
- Lab 5: Градиентный бустинг
- Итоговое сравнение всех алгоритмов

## Структура

- notebooks/ - Jupyter ноутбуки с экспериментами
- src/ - собственные реализации алгоритмов
- data/ - датасеты

## Запуск

pip install -r requirements.txt
jupyter notebook

Откройте нужный ноутбук в папке notebooks.
