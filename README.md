# Artificial Intelligence Labs

Репозиторий с лабораторными работами по машинному обучению (лабораторные 1–5).

## Структура

- `notebooks/` — Jupyter-ноутбуки с экспериментами
- `src/` — собственные реализации алгоритмов
- `data/` — датасеты

## Лабораторная работа №1 — KNN

Ноутбук: `notebooks/lab1_knn.ipynb`

- **Классификация**: Wine Dataset
- **Регрессия**: Parkinsons Telemonitoring Dataset
- Бейзлайн (sklearn) + улучшенный бейзлайн + собственная реализация

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook
```
